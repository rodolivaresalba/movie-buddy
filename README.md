# movie buddy

A minimal film recommendation app deployed to Vercel.

## Files
- `index.html` — responsive app
- `api/chat.js` — secure Vercel serverless API
- `package.json` — project config

## Environment variable
Create `OPENAI_API_KEY` in Vercel Project → Settings → Environment Variables (Production).

## Features
- GPT-4o mini adaptive either/or questions, custom text answers and Skip (maximum 8 questions)
- Three film suggestions, generated by the model
- One visible creativity / surprise slider, mapped to the real OpenAI `temperature` value (0–2)
- On the results page, **releasing the slider** regenerates three recommendations without redoing the questions. Requests are serialized to prevent stale content.
- Preview images are requested from Wikipedia, when an appropriate film-page thumbnail exists. No additional API key needed. Otherwise a styled text poster is displayed.
- No database, profiles, or persistent history

## Notes
The recommendations are generated by GPT, and film existence/year cannot be independently validated without a film catalogue. Wikipedia thumbnails can be missing or imperfect. Avoid claiming all images are official posters. No secrets belong in GitHub.
